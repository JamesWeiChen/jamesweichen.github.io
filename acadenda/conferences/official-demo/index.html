下載與匯入示範議程

掃描下方任一 QR Code，匯入附有兩張地圖的虛構會議範例。.acadenda 與 .json 兩種格式都包含「一樓會場配置圖」和「校園交通圖」，可用來測試議程匯入與會議地圖功能。

  1. 在 Acadenda 的「會議」分頁點「匯入」，選擇「從連結加入」。
  2. 點網址欄旁的 QR Code 圖示，掃描下方任一 QR Code。若正在同一支手機閱讀，長按下方下載連結複製網址，再貼到 App 的網址欄。
  3. 點「預覽行程」，確認會議名稱和項目數，再點「加入我的會議」。
  4. 匯入後開啟示範會議的「地圖」，應看到「Level 1 Venue Plan」（一樓會場配置圖）與「Campus Transport Map」（校園交通圖），點選任一張確認完整圖片。

若已匯入過這份範例，請在預覽後選擇更新既有會議，再開啟「地圖」。首次載入圖片需要網路。

兩張地圖均為原創虛構示意圖，非真實地點；PNG，1800 × 1200 像素，每張小於 100 KB。

DIRECT IMPORT · QR CODE / LINK

Download and import sample programs

Scan either QR code below to import a fictional conference with two maps. Both the .acadenda and .json samples include a Level 1 venue plan and a campus transport map, so you can try schedule import and conference maps together.

  1. In Acadenda, open Conference → Import → Add from a Link.
  2. Tap the QR code icon beside the URL field and scan either code below. On the same phone? Press and hold a download link below to copy its URL, then paste it into the app’s URL field.
  3. Tap Preview Schedule, check the conference name and counts, then tap Add to my conferences.
  4. After importing, open Maps in the demo conference. You should see “Level 1 Venue Plan” and “Campus Transport Map”. Open each to check the full image.

Already imported this sample? Choose to update the existing conference after previewing, then open Maps. An internet connection is needed to load the images for the first time.

Both maps are original fictional diagrams, not real locations. PNG, 1800 × 1200 pixels, under 100 KB each.
