Get Acadenda on the App Store
  1. Install Acadenda from the App Store.
  2. In Acadenda, open Conference → Import → Add from a Link.
  3. Paste the program link, or scan the QR code with the app’s scanner.
  4. Preview the schedule, then tap Add to my conferences.

The program link stays the same when the schedule is updated, so the QR code does not need to be replaced.
